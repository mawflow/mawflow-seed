# ChatGPT 到 AI 的通用交接

当 ChatGPT 或其它规划型助手需要把任务交给可执行 AI 时，使用普通 Markdown，至少包含：目标、范围、禁止项、验收标准、已知证据和期望交付物。

接收方 AI 必须先读取本项目 `AI_START_HERE.md`，遵守项目边界，并区分“已修改”“已验证”“已上线”和“已由真人验收”。不得把聊天中的账号、密钥或本机绝对路径写入仓库。

建议格式：

```markdown
# 任务：<一句话目标>

## 范围
- 允许修改：...
- 禁止修改：...

## 验收
- ...

## 已知证据
- ...
```

从 GitHub 等远程仓库接力时，附 owner/repository、branch/ref、commit SHA（不可得时标为未知）、已读路径与内容缺口；接收方先核对版本再实施。只读网页会话没有实际执行的测试、Git 写入和部署均标为未验证。
