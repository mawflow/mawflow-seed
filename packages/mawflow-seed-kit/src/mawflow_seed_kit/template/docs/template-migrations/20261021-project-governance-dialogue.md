# 项目口径与档案增量采用

本能力属于基于 2.15.0 的后续开发候选，尚未公开发布。Seed Contract 主版本保持 2，来源正文按 v3 演进。工作台和 CLI 应检测 `project.governance.v1` 能力；旧工具可继续读旧资料，不能降级写新记录。

1. 保留已有问答、来源、档案及项目私有配置。先核验当前源码/Kit/Host的协议支持，主仓按注册Seed提交增量采用，公共渠道项目只通过已验证公共稳定版本升级。
2. 增量合入 `docs/ai-coding/project-governance.md`、通用工具目录、来源捕获v3扩展与 `.maw/agent-entry.yaml` 对应项目治理节。Agent规则只新增相关条目。
3. 来源v1/v2保持可读，旧业务口径保留原确认范围和来源声明。业务、技术理解手动生成候选；不自动确认历史资料。
4. 执行问答提案→精确确认→context→消费回执验证；生成固定档案，并演练联合修订中断和同请求恢复。重试不能多写确认。
5. Host/CLI更新与项目采用分开记录。项目目录的脚本可供外部AI使用；Host只执行安装包中的可信实现。不要复制业务项目资料、真实确认记录或本机回执进入Seed。

回退 UI/Host 后保留新来源和版本文件；旧写器遇到v3必须拒绝，不能删掉新资料制造兼容。未完成档案不进入有效投影，可用同请求恢复。发布与真人验收另行记录。
