# 项目适用规则与采用

先根据当前 `.maw/project.yaml` 的分类选择新建、存量演进或探索项目，再按技术栈、组件、客户交付、网络和环境确定适用规则。已确认事实沿用；接管允许 accepted_with_gaps，但记录缺口和责任，不伪造历史任务、测试或部署。

规则分为统一总则、阶段规范、项目适用规则及经验资源。必需安全与证据边界共同遵守；技术栈、构建命令、数据库方言、页面尺寸、租户、网络路径、客户分支及部署脚本由项目确认。Seed不内置真实客户值，也不把某项目使用经验设为所有项目固定门槛。

外部规则进入项目时登记采用、改写、暂缓或排除及原因，只吸收对本项目有明确收益且不损害边界、验证或交付的规则。后续通过已吸收的项目权威执行；不在每次任务全量读取客户AGENTS、全部经验或全部docs。

采用矩阵至少记录 rule key、适用条件、采用决定、项目权威引用、确认依据、执行方式、实际检查入口、已接入/未接入状态和缺口责任。未注册测试套件不得报自动通过；脚本可用不代表业务测试已接入。规范修订先预览差异并增量合并；旧项目可以保留私有扩展，但不得声明已采用实际缺失的能力。

本地路径、预算、代理、凭证和设备绑定留在 `.local`；公共经验采用关系固定版本，技术包继续沿用 registry/lock。旧项目按自己的模板升级执行，不批量改其它项目，也不导入源仓真实来源事件、更新动态和验收历史。

采用结构示例见 [采用矩阵](examples/adoption-matrix.yaml)，pending和not_connected不得称已采用或已接入。
