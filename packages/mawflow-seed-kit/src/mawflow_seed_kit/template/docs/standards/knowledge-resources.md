# 经验与资源复用

规范、项目经验、共享/公开经验和资源分别维护。所有项目通用约束经确认、发行和项目升级进入Seed；项目特有契约/工具链留在项目；账号共享、工作空间共享、项目私有及平台公开是不同范围，扩大共享或公开沿用现有明确授权和审核。

## 阶段用途

立项找初始化案例，设计找架构/技术包，开发找历史问题，测试找用例/身份用途，部署找迁移/恢复经验，交付找可授权资料与采用记录。任务关键词检索安全索引，命中后只读必要正文，不扫描其它项目或私有会话。

经验条目使用现象、原因、适用条件、处理、验证、失败恢复、证据、版本和责任。项目发现先为candidate；补证据、脱敏、审核后选择项目内、账号/空间共享或平台公开。重复条目合并引用；过期经验标记待复核，不把一次项目成功作为所有环境有效。

资源采用依次执行发现、核验权限与适用条件、固定key/version/hash、当前项目验证、记录用途与结果。经验/文件引用的更新提示不自动换掉项目固定版本。测试身份只保存角色、环境、用途、状态、有效期及安全引用，真实凭证通过既有通道取得；正文不进入Seed、Kit或共享规则。

Framework/Style/Check/Verification等技术Pack继续沿用registry和lock，解析不授予安装、执行、部署或凭证领取权限。离线缓存仅供参考，恢复联网后重新鉴权。删除、撤权、账号切换和分享按平台既有范围执行，Seed不复制账号数据或平台私有API实现。

当前接入协议见 [资源库与经验库](../ai-coding/workspace-libraries.md)。平台实际能力、Host安装、公共发行、项目采用、验证和真人验收分别记录；文档存在不能证明全部已接入。
