# 立项与初始化清单

## 进入条件

用户授权新建、采纳或接管项目；已确定工作目录与仓库边界。只读观察不自动初始化、建分支或写配置。

## 规范分组

1. 目标与范围：价值、主要用户、需求成熟度、成功标准和不负责范围。
2. 新建/存量接管：记录真实源码、已有成熟事实及缺口；不创建假的历史任务。
3. 仓库与来源：核验身份、Seed版本/来源、Git和协作模式；默认空组件，显式 init/adopt。
4. 配置与责任：组件、模块候选、源码声明、环境/部署目标、凭证需求、资源需求和责任角色。
5. 本机准备：只读检查已有服务和工具；按需复用，设备重任务串行；不默认启动所有组件。

## 最小产物与完成条件

项目事实、范围、初始化/接管回执、允许路径、真实验证入口及带责任的待确认项。存量接管可带缺口进入后续工作；缺口影响相应任务，不自动把全项目判为失败。真实密钥、本机目录和网络端点不写入共享事实。新建、接管与探索分别按实际成熟度裁剪。
