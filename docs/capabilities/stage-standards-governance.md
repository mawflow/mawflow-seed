# 六阶段规范与任务证据治理

capability_key: stage-standards-governance

按 [阶段入口](../standards/README.md) 读取目录与命中权威。Seed Kit提供单一实现，Git与Kit物化包含相同目录、规范、模板及适配器。检查器执行只读目录/引用/声明/哈希核验；不执行任务、不授予权限、不证明真实活动。索引预览/指纹执行、空suite、证据失效及缺失采用分别验证。Contract保持2，旧项目通过受控模板升级增量采用。

规范执行扩展提供显式事实选择、待判断条件、任务规则指纹和执行证据协议；`plan-task` 只读生成绑定预览，`report-task` 只投影原任务引用。主实现由 Seed Kit 持有，旧 Kit 遇新声明返回升级缺口。详见 [执行协议](../standards/execution-protocol.md)，生命周期采用修订2并分离页面保留和控制回执。
