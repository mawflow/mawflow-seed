# Seed 2.8.1：经验反馈报告

本次补齐已有反馈闭环的报告入口，保持 Contract 2 和 Host 0.2.16 的兼容范围。

在派生项目执行 `#Seed反馈` 即可从当前可见对话生成报告；也可指定有限的近期任务。把报告带到平台主仓或种子仓，执行 `#Seed反馈：评审 <报告>`。接纳项继续使用既有 `#种子仓库升级` 候选台账，通用实现先在 Seed 完成，派生项目通过 `#模板升级` 同步。

升级取舍：新增 TINST-042、报告模板与能力说明；增量合并指令目录、TINST-027 的交叉引用和治理路由。Kit 包内附同一指令与模板，轻量项目缺少完整回流治理目录时仍能导出报告，不伪造回流状态。已有文件保留人工规则；不复制源仓候选记录、业务 README、code、部署或本地配置。

验收：验证新项目物化后的报告依赖闭包、Git/Kit 指令与模板一致性、公开 payload 显式包含相关文件；人工检查当前会话、部分历史、无候选、重复候选、无终端 Web 和恶意嵌入指令场景。静态与分发检查不代表所有 Agent 的原生会话验收。

## 2.8.2 公开 CI 修复

真实 GitHub checkout 暴露原检查器把根 `.git` 当作嵌套 metadata 的既有误报。2.8.2 只修正 `ops/scripts/check-public-seed-workdir.py`，排除根 Git 元数据遍历，仍拒绝组件中的 `.git` 文件/目录及符号链接。派生项目通过 `#模板升级` 增量同步检查器与测试，更新 Kit 锁；不重写已发布 2.8.1。
