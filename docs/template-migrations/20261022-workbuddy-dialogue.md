# WorkBuddy 文件对话修补采用

Seed/Kit 2.17.1，Contract 2。明确 WorkBuddy 身份复用 AGENTS.md，未知工具继续通用回退；入口按需导航 seed.lock 与 template-source，区分项目版本与已安装工具版本。

已有项目先预览官方迁移计划，保护项目身份、README、源码、组件/模块、生命周期、发布及仓库映射、私有规则和历史来源。共享 agent-entry/rules 增量迁移；AI_START_HERE.md 的版本来源、有界读取与记忆边界段落，以及 CHATGPT_TO_AI.md 的来源接续说明需语义合并，不整页覆盖项目内容。

可变检查点不作为仍要修改的事件哈希证据；原事件JSON和派生content_contract区分，保留可复现回读步骤，不删除旧来源绕过幂等；来源摘要不能证明Git、功能或资源状态。运行环境由控制侧准备和核验，不分派给WorkBuddy安装或升级。

实际客户端默认加载、只读及授权修改边界需在采用后新会话分别验证，静态ready不等于运行验收。该修补不提供CLI派发或操作系统写隔离。
