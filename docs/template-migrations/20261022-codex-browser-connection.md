# 浏览器连接经验增量采用

本改动是Seed开发候选，未因Git推送而公开发布。它增加浏览器连接规范、按需读取路由和Agent提示，不要求安装独立代理或修改本机网络。

1. 按当前仓库身份解析来源：经核验的主仓使用已注册Seed独立Git目录的固定提交，其它派生项目只通过经验证的公共稳定版本及同版本Kit采用；没有新稳定版时保留当前版本。
2. 新增`docs/ai-coding/browser-connection.md`及本说明；增量合并`.maw/agent-entry.yaml`的browser_automation路由和execution_contract.browser_connection、`.maw/agent-rules.yaml`的browser_connection_recovery，以及各Agent托管入口的一行提示。保留项目自有规则、用户指定入口及完整的本机配置。
3. 有完整经验索引的Git项目加入`EXP-036`；若该ID已被项目占用，用项目空闲ID回链同一规范，不覆盖其它经验。Kit通过读取路由与Agent规则直接定位，无须复制源仓真实经验台账。
4. 检查规范及链接、工具首次调用要求、同名自动生成配置保护、MCP重载和JS重置区别。使用Kit时在空目录物化，确认生成入口能找到规范；旧项目迁移先预览，保留定制内容。
5. 本地运行验证只在当前授权设备执行。分别记录官方/代理发现、真实开页与点击刷新；能力缺失或待用户重连时如实标记，不能因采用规范称浏览器已修复。

回退只撤销本次共享规范和路由合并，保留项目事实、来源记录、用户偏好与设备配置；不关闭他人页面或停止共享服务。Seed/Kit正式发布、项目采用和真实运行验收分别记录。
