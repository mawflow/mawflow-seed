# 开发与集成清单

## 进入条件

已有实现授权，模块或候选范围、allowed/blocked路径和验收目标明确。

## 规范分组

- 开工：查当前事实、适用规则、任务关键词经验及已有公共能力；只读取命中的必要正文。
- 实现：沿用项目编码、脚本、错误处理、接口及数据库规范；保持真实错误与输入，不用假成功掩盖未接入。
- 协作：独立任务基线、路径、工作树及写租约；共享分支串行集成，重新核对输入变化。
- 资源：按需复用服务和可信缓存，构建/集成等重任务按设备预算串行；不重复构建同一可信输入。
- 集成：变更公共类型、依赖或构建配置时扩大相关验证；范围外缺口提报责任方。
- 收口：同步受影响模块事实/设计，追加必要来源事件与用户可见更新，提交推送并按有效镜像计划处理。

## 最小产物与完成条件

实现、定向验证、必要文档与未完成项。实现完成只推进本范围实现维度，不自动发布或验收。旧失败和本次新增失败分别说明。缓存与已验收步骤可复用的前提是源码、配置、构建环境、目标基线和证据仍匹配；输入变化只失效受影响部分。
